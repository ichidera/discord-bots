# discord-bots
An archive of my Discord Bots

## Docker Compose

If you have a `docker-compose.yml` at the repository root, build and run the services with:

```bash
docker compose build
docker compose up -d
```

To rebuild after code changes:

```bash
docker compose build --no-cache
docker compose up -d
```
